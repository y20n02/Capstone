# Capstone Project

카타르시스 기반 인터랙티브 미디어아트 프로젝트 (Unity + Leap Motion)

---

## 프로젝트 개요

본 프로젝트는 관람객의 손 제스처 및 움직임 입력(Leap Motion)을 기반으로  
감정의 흐름을 단계적으로 체험하도록 설계된 인터랙티브 미디어아트 작품이다.  

Unity 환경에서 제스처 인식, 단계 전환, 시각·청각적 연출을 결합하여  
축적 → 자극 → 표출 → 정화의 서사 구조를 경험할 수 있도록 구성되어 있다.

---

## 인트로 · 아웃트로 영상 안내

본 프로젝트에는 **인트로 영상과 아웃트로 영상이 실행 흐름에 직접 포함되어 있다.**  
해당 영상들은 데모 영상이 아니며, 프로젝트 시작과 종료 시 실제로 재생되는 **필수 에셋**이다.

GitHub 저장소의 용량 제한으로 인해 영상 파일은 레포지토리에 포함되어 있지 않으며,  
프로젝트 실행 전 반드시 로컬에 추가해야 정상적인 실행과 연출을 확인할 수 있다.

## 영상 파일 추가 위치
다운로드한 영상 파일을 아래 경로에 추가한다.

Assets/
└─ Video/
├─ intro.mp4
└─ outro.mp4


파일명과 확장자는 프로젝트에 설정된 참조 기준에 따라 정확히 일치해야 한다.  
파일명이 다르거나 해당 경로에 존재하지 않을 경우 인트로 및 아웃트로 영상은 재생되지 않는다.

---

## 실행 방법

1. 본 레포지토리를 클론한다.
2. 위 안내에 따라 `Assets/Video/` 폴더에 `intro.mp4`, `outro.mp4` 파일을 추가한다.
3. Unity에서 프로젝트를 연다.
4. 메인 씬을 실행한다.  
   인트로 영상 재생 후 인터랙션이 진행되며, 체험 종료 시 아웃트로 영상이 재생된다.

## 개발 환경

- Engine: Unity
- Language: C#
- Input: Leap Motion (Hand Tracking)
- Platform: Windows / macOS

## 참고 사항

인트로 및 아웃트로 영상이 없는 경우에도 프로젝트는 실행될 수 있으나,  
의도된 서사 구조와 연출 경험은 완전하지 않다.  
정상적인 체험을 위해 실행 전 영상 파일 추가 여부를 반드시 확인해야 한다.
